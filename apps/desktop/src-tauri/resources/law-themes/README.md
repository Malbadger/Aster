# Aster Workbench Themes

This bundled VSCodium extension keeps the embedded editor synchronized with
Aster's application theme. It contains the same eighteen palettes exposed by
Aster Settings → Appearance, including Aster Graphite, Paper, Midnight, and High
Contrast plus the fourteen imported editor palettes.

Aster installs this extension into its isolated application profile. It does not
change the user's standalone VSCodium extensions or settings.
