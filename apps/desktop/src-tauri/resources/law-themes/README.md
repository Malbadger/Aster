# LAW Workbench Themes

This bundled VSCodium extension keeps the embedded editor synchronized with
LAW's application theme. It contains the same eighteen palettes exposed by
LAW Settings → Appearance, including LAW Graphite, Paper, Midnight, and High
Contrast plus the fourteen imported editor palettes.

LAW installs this extension into its isolated application profile. It does not
change the user's standalone VSCodium extensions or settings.
